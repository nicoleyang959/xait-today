# Project library extension

Scope: private project saving inside the incumbent daily reader. Visitor mode:
Operate for the library, Read for the unchanged briefing. Confirmed by the
implementation plan; no new visual identity or concept selection is required.

## Direction contract

THESIS: Save a useful project immediately, then research it deliberately. A
compact save action must not stretch the GitHub table or interrupt reading.

OWN-WORLD: Inherit all seven existing theme palettes, system-font stacks,
borders, surface tokens, and familiar form controls. No new brand, decorative
imagery, cards-within-cards, or remote fonts.

STORY: The reader saves, sees an honest local/cloud state, opens My projects,
adds a private note, and resumes the exact briefing position.

FIRST VIEWPORT: Preserve the masthead and add one My projects entry. The saved
view replaces only the reading area: account/sync feedback first, search and
status controls next, then an aligned list and inline editor. Mobile becomes
one column with labelled controls, visible focus, and no horizontal overflow.

FORM: User-pinned same-page #saved extension, code-led. Signature interaction:
one local transaction changes a compact save button to saved/pending, with a
separate cloud-acknowledged state. seed: none (unavailable).

FINISH: unreviewed and undocumented is unfinished; this build ends with the
finish review, the verdict, DESIGN.md, and every shipping raster carrying its
provenance. No raster assets are required by this extension. Real cloud and
multi-device acceptance remain explicitly gated on human configuration.
